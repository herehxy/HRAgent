# HRAgent 招聘工作台 · 使用指南

适用版本：**v3.1.15**（Windows 单机 / 内网离线可用）
最后更新：2026-10-28

---

## 一、安装与启动

### 1.1 两种方式，选一种

| | 便携版 | 安装程序 |
|---|---|---|
| 文件 | `HRAgent工作台-v3.1.15-便携版.zip` | `HRAgent工作台-安装程序-v3.1.15.exe` |
| 怎么用 | 解压到任意文件夹 → 双击 `HRAgent工作台.exe` | 双击 → 选安装位置 → 安装 → 自动建快捷方式 |
| 数据位置 | 程序目录下 `data\` 和 `config\` | **安装目录**下 `data\` 和 `config\` |
| 适合 | 放 U 盘、换机器、不想装 | 固定一台机器长期用、要桌面快捷方式 |

两种方式的数据都跟着程序目录走。**换机器时整个目录一起拷**才带得走数据 —— 只拷 exe 是没有数据的。

安装程序默认装到 `C:\Users\<你>\AppData\Local\Programs\HRAgent工作台`，这个位置不需要管理员权限。建议改成 `D:\HRAgent工作台` 这类好找的位置。

### 1.2 安装程序报 WinError 5 / 拒绝访问

说明这台机器的安全软件拦了**未签名程序**的写操作。改用包里自带的 `安装.cmd`：

1. 把便携版解压到目标位置
2. 双击其中的 `安装.cmd`
3. 它用 `robocopy` + `PowerShell` 完成复制、建快捷方式、写卸载信息 —— 这两个都是微软签名工具，不受那条策略限制

### 1.3 安装时保留旧数据

- 安装界面第二步可以填**旧版目录**；全新安装直接回车跳过
- 只有目标目录里**还没有** `workbench.db` 时才迁移，已有数据库绝不覆盖
- 迁移是**复制**，旧目录原样保留，确认新库能用后再自行删除
- `master.key` 会一起带过来 —— 丢了它，电话号码和邮箱就解不开了
- 卸载只删程序文件，`data\` 和 `config\` 保留

### 1.4 启动后发生什么

1. 后台起服务（本机 `127.0.0.1`，默认端口 **8756**，被占用会自动顺延到 8765 / 8865 段）
2. 右下角出现**托盘图标**
3. 自动打开浏览器 → 就是工作台界面（一次启动只开一个标签页）

浏览器没自动打开时：右键托盘图标 →「打开工作台」，或手动访问托盘菜单里显示的地址。

已经在跑的时候再双击一次，会直接指到已打开的那一页，不会再起第二份。

托盘菜单：**打开工作台 / 打开数据目录 / 安装热更新包… / 退出（停止服务）**。

### 1.5 第一次启动会稍慢

程序会做一次历史数据修补（技能清单重算、岗位建议清理），几十秒内完成，期间界面已经可用。第二次起不再重复。

## 二、首次登录与账号权限

### 2.1 默认账号

| 情况 | 账号 | 口令 |
|---|---|---|
| 全新安装 | `admin` | `change-me` |
| 从旧版升级 | 原来的 `hr`（自动提升为管理员） | 原口令不变 |

登录页会直接把还没改过的默认口令提示出来；一旦改过，这条提示就不再显示 —— 所以别把它当成"泄露"，它是首次部署的引导。

> **登录后第一件事**：进「账号管理」把 `change-me` 改掉。

### 2.2 三种角色

| 角色 | 能做什么 |
|---|---|
| 招聘 HR（`hr`） | 日常全部招聘操作：看人、改档、推进阶段、写备注、导入、发邮件、用助手、改系统配置 |
| 系统管理员（`admin`） | 在 HR 之上再加**账号管理**；其余完全一样 |
| 只读观察（`viewer`） | 只能查看候选人和岗位，不能改动任何数据，也不能生成待确认提案 |

系统一共 13 个权限点（查看、看完整联系方式、用助手、生成提案、确认提案、改阶段、写备注、合并、导入、导出、归档、系统配置、账号管理）。「账号管理」页底部有一张**权限矩阵**，哪些角色有哪项权限一目了然。

只读角色登录后，"会改数据"的入口会自动隐藏。

### 2.3 账号管理（仅管理员可见）

- **新建账号**：填账号名（登录用，建好后不能再改）、初始口令（至少 8 位）、角色
- **改角色**：下拉直接生效
- **重置口令**：设新口令，该账号需要重新登录
- **停用 / 启用**：停用后该账号立刻失效。不能停用自己

### 2.4 顶栏

登录模式下顶栏右侧显示当前用户，点「退出」回到登录页。

### 2.5 关闭登录（仅单机排障用）

设置环境变量 `TP_AUTH=0` 后启动，就不再要求登录 —— 任何能打开这个地址的人都是全权限。**只在单机自用或排障时这么干**，共享电脑上不要关。

## 三、界面总览

- **人才库** —— 主工作区：找人、筛选、看档案、推进流程
- **智能助手** —— 用自然语言下指令（改数据要你点确认）
- **写邮件** —— 面试邀请 / 录用通知 / 其他通知
- **岗位管理** —— 建岗位、写 JD、按新 JD 重算
- **归档** —— 已归档的人，可恢复
- **系统配置** —— 模型、邮箱、模板、导入来源等
- **账号管理** —— 仅系统管理员可见

右侧默认显示「概览 · 待办」：今天该处理谁、各阶段人数分布。

## 四、导入简历

三种来源，都在人才库左上角：

1. **导入本地文件夹** —— 选一个放简历的目录，递归导入 PDF / Word / 图片 / txt
2. **收取邮箱简历** —— 配好 IMAP 后自动收取附件
3. **上传简历照片/文件** —— 手机拍的纸质件、扫描件，选文件直接入库

### 导入时发生什么

```
解析（PDF/Word/图片 OCR）
  → 结构化抽取（姓名/学历/院校/专业/年限/技能/联系方式）
  → 去重（同一人只留一条，可撤销合并）
  → 归岗（按邮件标题或 JD 匹配岗位）
  → 判档（学历门槛 + 技能命中 + 证据核验）
  → 可选：调模型写分析结论
```

- 扫描件 / 照片走**本地 OCR**，不外传
- 技能必须有原文证据：抽不到证据的标为「未核验」，不计入岗位命中
- 导入是后台任务，进度在顶部进度条；可以中途停止，已处理的不回滚

### 一封邮件只建一个档案

同一封邮件里即使附了两个人的简历，也只按**第一份简历**建档，其余附件记为"其他附件"。多余的人请让对方单独发一封，或手动上传。

### 邮箱收取的人数说明

顶部显示的是**邮箱里的邮件总数**，不是新导入的人数。同一个人的重复投递会被合并成一条，所以"收到 1000 封"和"新增 700 人"是两个不同的数，不是出错。

## 五、人才库

### 5.1 找人

- 搜索框：姓名 / 岗位 / 院校 / 专业 / 技能 / 学历，回车或点「搜索」；输入过程中不查，清空自动恢复全部
- 筛选器：学历（多选）、档位、阶段、性别、院校层次（985/211/特殊）、第一学历、四六级（多选）、海外院校、面试结论、面试部门、投递时间段
- 每个筛选项后面带人数，是"选它会剩多少人"的预览

### 5.2 列表

- 一页 25 人，底部可翻页、改每页条数
- 每行：头像 · 姓名 · 阶段标签 · 结论标签 · 学历院校 · 岗位 · 档位
- 徽章只标真需要动手的事：**待归岗 · 待分析 · 待复核 · 简历读不出 · 缺姓名/年限**
- 勾选多人可对比档案（最多 10 个）

### 5.3 「管道」视图

按阶段看板：全部简历 → 初筛通过 → 待面试 → 已面试 → 已发放 offer → 已结束。每列最多 15 人，超期的人标红，行内下拉可直接推进阶段。

## 六、完整档案（右侧）

点左侧任意一行，右边显示这个人的完整档案：

| 区块 | 内容 |
|---|---|
| 基本信息 | 姓名、学历、院校、专业、年限、性别、电话、邮箱、现单位（点一下淡灰文字即可修改） |
| 教育经历 | 逐段显示，带软科排名 / QS / 985·211 标签；每段可单独改 |
| 技能与证据 | 每个技能后面附原文片段，方便核对 |
| 荣誉 / 论文 / 专利 | 逐条验过原文的才显示 |
| 系统分析 | 模型写的一段结论 + 风险点 |
| 面试与录用 | 面试单位、时间、时段、方式、结论 |
| 简历原件 | 打开 / 下载 |
| 操作记录 | 谁在什么时候改了什么（审计） |

改完点右上「保存」：只提交真正改过的字段，没改的不会覆盖，并写一条审计。换人时已填未保存的内容会提示，右栏整块淡入、滚动位置回到顶部。

## 七、阶段与结论（招聘流程）

阶段（走到哪一步）与结论（结果如何）是两件事，分开记。

| 阶段 | 允许打的结论 |
|---|---|
| 全部简历 / 初筛通过 | —— |
| 待面试 | 拟录用 / 不录用 |
| 已面试 | 拟录用 / 不录用 |
| 已发放 offer | 已签约 / 拒签 |
| 已结束 | —— |

- 结论标签只在该阶段显示，人走到下一阶段后旧结论自动不再显示
- 「已结束」会把这个人自动归档
- 阶段推进和结论都写入审计

## 八、写邮件

两步式：**先出草稿，再由你点发送**。系统任何时候都不会自动发信。

**选收件人**：从候选人里选，自动带出邮箱和档案里已填的面试单位 / 时间 / 时段 / 方式。换人时这些自动带出的值会被覆盖，手填的不动。

**选模板 + 填变量**：模板分「面试邀请 / 录用通知 / 其他通知」三类，可自己新建。正文里的 `{姓名}` `{面试时间}` 等占位符会替换成变量值；变量输入框只显示当前模板用得上的那几个。正文支持富文本（加粗、列表、表格）。

**附件与发送**：从候选人简历原件里挑，或临时上传；附件合计上限 20MB。点「发送」后确认框会列出收件人、主题、附件名，确认才真发。发送结果留在页面上（成功凭据 / 失败原因），可重试。

重复点击不会重复发：同一请求有 ID 去重。

## 九、智能助手

用自然语言下指令，例如：

- 「还有哪些人没归岗？」
- 「把待归岗的人归到数字化工程师」
- 「今年那个岗位 JD 改一下，按新 JD 重算」
- 「把去年投过的人归档」

### 铁律：改数据必须你点头

助手不会直接改任何东西。它只生成「待确认提案」，你在提案列表里逐条「确认执行」或「拒绝」，全部写审计。批量动作会先说影响面，例如"其中 12 人归档已满 30 天将被彻底删除"。

**助手故意做不到的事**：发邮件、发消息、通知候选人、拒绝候选人、删除候选人、删除简历。

## 十、岗位管理

- **新增岗位**：填名称 + JD（JD 决定技能要求和学历门槛）
- **改 JD**：只改配置，不会自动改历史档案的档位
- **按新 JD 重算**：单独按钮触发，会先给你看"哪些人的建议档变了"，确认后才落库
- **停用**：不删除，停用后不再参与归岗

---

## 十一、归档

- 归档 = 收起来，**不是删除**。档案、投递、附件全部保留
- 已归档的人不再出现在人才库和检索里，在「归档」页，可随时恢复
- **⚠ 归档满 30 天会被彻底清理**：数据库记录与简历原件真删除、不可恢复（审计日志永久保留）。想长期留底的人，别归档或及时恢复
- 归档页也提供「彻底删除」，用于候选人要求提前删除的场景

只有「已结束」阶段会自动归档；其它阶段归档需要手动操作或经助手提案确认。

## 十二、系统配置

| 项 | 说明 |
|---|---|
| 模型设置 | 服务地址 + 模型名 + API Key。任何 OpenAI 兼容服务都能接（vLLM / Ollama / Xinference / 内网自建） |
| 收信 | IMAP 服务器、邮箱、授权码（加密存储） |
| 发信 | SMTP 服务器、端口、账号、授权码 |
| 邮件模板 | 增删改 |
| 导入来源 | 文件夹路径、邮箱规则 |
| 其它 | 入库即分析开关、超期天数、保留天数 |

「入库即分析」打开时，每份新简历入库就调模型出结论（每人约 2–8 秒）。想省额度可以关掉，之后手动批量补。

## 十三、数据与备份

### 数据在哪

| 版本 | 路径 |
|---|---|
| 便携版 | `<程序目录>\data\`、`<程序目录>\config\` |
| 安装版 | `<安装目录>\data\`、`<安装目录>\config\` |

关键文件：

```
data\workbench.db        数据库（全部档案/投递/审计）
data\master.key          加密密钥（电话邮箱靠它解密）
data\archive\            简历原件
data\avatars\            抽出来的证件照
data\attachments\        邮件附件
config\*.json            岗位 JD、技能本体、阶段、模型、邮箱配置
```

### 备份

关掉程序后整份复制 `data\` 和 `config\` 即可。

**`master.key` 必须一起备份** —— 单独拷数据库到别的机器，联系方式会全部显示为"—"。

### 换机器

1. 旧机：退出程序（托盘右键「退出」）
2. 拷 `data\` + `config\` 到新机对应位置
3. 新机：启动 → 自动接管

## 十四、常见问题

**双击没反应 / 只有后台没有托盘图标**
1. 任务管理器看是否已有 `HRAgent工作台.exe` 在跑（只允许一个）
2. 右键托盘图标 →「退出（停止服务）」，再重新打开
3. 仍不行：任务管理器结束所有 `HRAgent工作台.exe` 后重开
4. 还不行：运行 `HRAgent工作台.exe --port-check`，会生成一份端口体检报告

**装的时候提示 WinError 5 / 拒绝访问**
见 1.2：安全软件拦了未签名程序的写入。改用便携版，或双击包里的 `安装.cmd`。

**登录进不去 / 忘记口令**
- 全新安装的默认账号是 `admin`，口令 `change-me`
- 忘记口令：让另一台管理员账号在「账号管理」里点「重置口令」
- 只有一个管理员又忘了口令：先用便携版挂到同一份数据目录上，或联系维护人员

**提示"数据库正忙"**
后台正在整理数据（首次启动的修补、批量导入、批量重算）。等几秒重试即可，不是坏了。反复出现就检查是不是开了多个实例。

**启动弹了好几个浏览器标签页**
v3.1.15 已修：一次启动只打开一个页面。若还出现，说明机器上同时跑着多个实例，按第一条清理后重开。

**头像不显示**
头像是从简历原件里抽的，首次要看时才后台抽，抽好之前显示姓名首字。档案右上角有「重新抽取」；抽错了可「去掉」。纯文字简历本来就没有照片。

**打开档案提示"简历读不出"**
那份 PDF 是扫描件且 OCR 引擎不可用。请直接「打开原件」人工核对，不要只看自动字段。

**电话 / 邮箱显示"—"**
`master.key` 丢了或不匹配。从原机器的 `data\master.key` 拷回来即可（数据库不用动）。

**导入后人数不对**
- 同一个人重复投递会合并成一条，不是丢了
- 同一封邮件只建一个档案（见第四章）
- 被判定重复的可「拆分」恢复
- 看首页统计的 `people_total`（含归档）与 `people`（未归档）对比

**页面打不开 / 地址变了**
端口被占时会自动顺延（8756 → 8765 → 8865）。托盘菜单里显示的就是当前实际地址。

## 十五、版本与升级

- 版本号显示在登录页 / 页脚，也可看程序目录的 `version.json`
- **安装版升级**：运行新版安装程序，程序文件覆盖，数据不动
- **便携版升级**：解压覆盖到原目录，保留 `data\` 和 `config\`
- 托盘菜单「安装热更新包…」可装 `HRAgent-update-vX.Y.Z.zip`（只替换程序，不动数据）

## 附：一句话记住三条

1. **改数据要你点确认**，助手不会自己动手
2. **归档不是删除**，可恢复；但满 30 天会真删（含原件）
3. **`master.key` 和数据一起备份**，单独拷库等于把联系方式丢了
