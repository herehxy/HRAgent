# 2.0.0 老用户升级到 v2.2.5 · 操作指南

面向对象：已经在用 **2.0.0**（或更早）版本的其他 HR。
核心承诺：**旧数据一个字节都不改、不删**，只做"复制"。

---

## 一、先搞清楚一件事：数据在哪

2.0.0 是"解压即用"版，数据跟着程序目录走：

```
<2.0.0 解压目录>/
  HRAgent工作台.exe
  _internal/
    data/          ← 你的库和简历原件在这
      workbench.db
      archive/      ← 已入库的简历原件
      resumes/      ← 待导入的来源文件夹
    config/        ← 你的配置（邮箱、模型、来源目录设置）
```

v2.2.5 换了位置：程序和用户数据**分开**。

```
<安装目录>/           ← 程序（可随时重装）
%LOCALAPPDATA%\HRAgentData\    ← 你的数据（升级不动这里）
  data/
  config/
```

所以升级 = **把上面那堆"用户数据"从旧目录搬到新目录**，程序部分直接换新的。

---

## 二、升级步骤（推荐路径）

### 第 1 步：先关掉旧版

托盘图标右键 → 退出。**别只关浏览器窗口**（服务还在后台跑，文件被锁住）。

### 第 2 步：不要删旧目录

把旧的 `HRAgent工作台` 文件夹**整个留着**，改名成 `HRAgent工作台_旧版` 更保险。
它是你的备份 —— 万一新版有问题，可以改回去继续用。

### 第 3 步：装 v2.2.5

双击 `HRAgent安装器.exe`：

| 选项 | 说明 |
|---|---|
| 安装路径 | 建议装到**新目录**（默认 `%LOCALAPPDATA%\Programs\HRAgent`）。装回旧目录也行，但那样"旧目录"就变成新目录了，**升级前的备份就没了** |
| 勾选「从旧安装目录迁移数据」 | **保持勾选**。安装器会自动找你的 2.0.0 目录 |
| 选择旧安装目录 | 安装器找不到时，手动选那个 `HRAgent工作台_旧版` 文件夹（**选外层那一层**，不用选到 `_internal`） |

安装器会打印这一行，就是成功的标志：

```
· 发现旧数据：D:\...\HRAgent工作台_旧版（12 人）→ 迁移到 C:\Users\...\AppData\Local\HRAgentData
[OK] 旧数据已迁移：{'candidates': 12, ...}（旧目录保持原样）
```

### 第 4 步：启动与核对

启动后按这几条核对（**都在「系统配置 → 导入与来源」和「人才库」里看**）：

1. 人才库里候选人数量 = 迁移日志里的 `candidates` 数
2. 「导入与来源」里**来源目录**显示的是 `%LOCALAPPDATA%\HRAgentData\data\resumes`，
   不是旧目录的路径
3. 随便点一个候选人 → 「在线打开」能出简历

## 三、换机器 / 换目录怎么办

2.0.0 的 `config/mailbox.json` 里存的是**绝对路径**（比如 `D:\HRAgent工作台\_internal\data\resumes`）。
换机器或目录变了，这个路径就失效 —— 症状是：

> 「导入与来源」显示**目录不存在**，点「在线预览」全部 404

v2.2.5 会**自动修正**这个值：启动时把指向旧位置的目录改成当前数据根下的同名子目录。
日志里会出现：

```
[i] 配置路径已修正：folder_dir：D:\HRAgent工作台\_internal\data\resumes → C:\Users\...\HRAgentData\data\resumes
```

修正前会自动备份成 `mailbox.json.bak_pathfix-<时间戳>`。

**你自己指定的外接盘目录不会被改** —— 只有指向旧程序目录的才会被改。

## 四、旧数据能支撑新版的哪些功能

| 能力 | 2.0.0 的数据够不够 | 说明 |
|---|---|---|
| 人才库、投递记录、档位 | ✅ 够 | 候选人/投递/技能表结构没变 |
| 简历原件（在线打开、下载） | ✅ 够 | 原件跟着库一起搬过来了 |
| 待导入来源目录 | ✅ 够 | 配置路径已自动重写到新数据根 |
| 附件/头像 | ✅ 够 | `avatars/` 目录一起搬 |
| 邮件（收信/发信） | ⚠️ 需重填凭据 | 授权码**不随包分发**（安全策略），升级后要重新填邮箱授权码和模型 API Key |
| 语义检索 | ⚠️ 需重建索引 | 换 embedding 模型时旧向量会失效，程序会自动重建 |
| 智能体提案、审计日志 | ✅ 自动补齐 | 新增的表/列启动时自动创建，老数据不受影响 |

**唯一需要人工做的**：重新填两个凭据（邮箱授权码 + 大模型 API Key）。
这是刻意的设计 —— 交付包不带真实凭据，避免泄露。

## 五、遇到问题怎么办

### 「目录不存在」/「路径不对」

1. 打开 `%LOCALAPPDATA%\HRAgentData\data\webapp.log`，搜 `配置路径已修正`
2. 没看到 → 说明来源目录不是指向旧程序的路径，是**你自己设的**：在
   「系统配置 → 导入与来源」里把来源目录改成实际位置，保存
3. 改了还在 → 看日志里 `原件不在磁盘上` 那几行，里面的路径就是它实际在找的地方

### 打开新版后是空库

说明迁移没跑到。检查：
- 安装时是否勾了「从旧安装目录迁移数据」
- 旧目录是否还在（迁移是"复制"，删了就找不到了）
- 手动重来：装一次，在安装器里手选旧目录

### 想完全从头来

卸载时勾「同时删除用户数据」，或直接删 `%LOCALAPPDATA%\HRAgentData`。
**旧目录里的原始数据始终不动。**

---

## 六、给 IT/HR 的一句话版本

> 装新版 → 装的时候勾「从旧安装目录迁移数据」→ 装完确认人才库人数对得上 →
> 在「导入与来源」里确认来源目录变成新路径 → 重新填邮箱授权码和模型 Key。
> 旧文件夹**别删**，那是备份。
