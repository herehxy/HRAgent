# 6.6.0 更新说明 · 智能助手能力扩展

日期：2026-11-25

## 6.6.2 补充（2026-11-26）

- 设置页读取配置增加超时与防重复打开：任一配置接口卡住时给出失败原因和「重试」，
  不再永远停在“读取配置…”；失败的配置不渲染成空值，避免误保存覆盖。
- 隐藏的登录表单不再保留可用的密码框，Chrome 保存的账号不会再灌进候选人搜索框；
  搜索框聚焦前 readonly，聚焦后正常输入。
- 邮件导入完成后自动刷新人才库列表、概览和待确认提案，不需要用户手动刷新网页。
- 无附件的投递邮件（标题/正文能识别出姓名、电话、邮箱等）会按邮件正文建档；
  通知/简报不会误建。

## 6.6.1 补充（2026-11-26）

长任务不再只有“回答仍在生成…”：导入/收取简历在助手气泡里显示完成数、进度条、
当前文件/邮件主题、分项计数和最近 8 条处理明细；刷新或切回会话后从
`/api/agent/trace` 接回同一份进度；进度上报是旁路，不影响导入本身。

## 一句话

这次不是“换更大的模型”，而是把 HR 已经在界面上能做的事，**补进智能助手的工具边界**，
并针对 27B 级别的小参数模型收紧路由、补 SOP、固定汇报口径。

## 修复的真实问题

截图：HR 说「导入邮箱最新简历」，助手只扫了本地待导入目录，回答「目录为空」。

根因：这句话被路由到 `mail` 组，而真正执行导入的 `ingest_resumes` 只放在 `admin` 组；
模型看不到执行工具，只能用手边的 `list_source_files` 扫目录。

现在：

- `mail` / `admin` / 新增 `import` 组都带 `ingest_resumes`；
- 即使历史消息把 `mail` 顶成主组，导入工具也不会消失；
- 系统提示词明确：导入/收取简历直接调工具，不要说“系统不支持对话触发”；
- 导入返回为空时自动附带诊断，不再反问“要不要帮你查历史”。

## 新增能力

| 能力 | 工具 | 说明 |
|---|---|---|
| 收邮箱 / 导文件夹 | `ingest_resumes`（增强） | 真执行，返回新增/同人新版本/重复/超大/失败与新候选人姓名 |
| 导入诊断 | `import_diagnostics` | 邮箱模式、账号、密钥、目录、超大、最近错误逐项体检 |
| 今日待办 | `daily_brief` | 直接读今日优先级，不额外调模型 |
| 能力清单 | `assistant_capabilities` | 回答“你能做什么”的权威来源，含明确限制 |
| 岗位详情 | `job_detail` | 完整 JD、门槛、阶段分布、最近投递 |
| 多投递时间线 | `get_candidate` 增加 `submissions` | 投了几次、几次同一份、每次时间 |

## 检索与导出

`search_candidates` 与 `export_roster` / `export_resume_bundle` 新增并打通：

- `school` / `major`：显式字段筛选，院校支持“西电/北邮/华科”等简称；
- `strong`：特定强势院校；
- `cet` / `overseas` / `bachelor` / `interview_unit` / `outcome`；
- `date_from` / `date_to` / `interview_date`；
- `archived=false/true/all`：归档的人也能查；
- 返回 `count`（总命中）+ `returned`（实际返回），避免把“返回 20 人”说成“只有 20 人”。

## 27B 适配

- 参数量 ≤32B 时注入“小参数模型执行纪律”：每轮 1–3 个必要工具、数字原样来自工具、
  参数枚举照说明、多步任务按步骤执行；
- 可见工具上限收紧到 18，减少弱模型在相似工具间摇摆；
- 新工具统一返回 `summary` / `counts` / `next_actions`，先读摘要再看明细。

## 其他

- 邮箱无进度条调用（助手/CLI）原来固定只收 200 封，现已尊重 `limit=0`（全部），与界面一致；
- 新增 23 条回归测试，覆盖路由、诊断、检索筛选、多投递、岗位详情、能力清单；
- 现有测试通过（`test_context_governance` 的 Windows 临时文件清理报错为历史问题，单跑仍复现，与本次无关）。

## 边界没变

- 写操作仍只生成待确认提案；
- 不能代 HR 发邮件（只能起草）；
- 不能物理删除（只能归档/回收站）；
- 聊天附件不会自动入库，必须 HR 点「入库」。
